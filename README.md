Spliceosomal ribozyme assembly (bioRxiv, 2026), supplementary files

Predicted structure of the human U5 snRNA Loop1 paired with the exons and the non-canonical pair of the intron ends (guanines) - the pre-catalytic stage. The input text file has three RNA sequences: human U5 stem-loop1, 5’ exon - intron G+1, intron G-1 – 3’exon. Below brackets indicate RNA bp positions. Intron G+1 - G-1 pair is set in WWt configuration (2nd Westhof geometric family, Leontis et al., 2002). The pdb file was generated online using SimRNAweb v2.0 created in the Lab of Professor Janusz Bujnicki (Moafinejad et al., 2024). This algorithm works with inputs of multiple RNA chains and since v2.0 takes Westhof bp classification as ‘Hard Pair Restrictions’.
